# Support ChatGPT Remote Control

Support pairing the Pi-backed Codex server as a Connected host through OpenAI Remote Control. Enrollment, pairing, relay transport, reconnection, client management, and message delivery remain in scope; a directly exposed app-server WebSocket does not replace them.

Amended on 2026-10-15: iOS device testing is optional and is not a release gate. The maintainer has no iOS device. Record unverified client coverage explicitly instead of claiming successful acceptance or blocking release on unavailable hardware.
